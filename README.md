# Idan Badin - Portfolio Website

The source code for my personal portfolio site: [idanbadin-portfolio.netlify.app](https://idanbadin-portfolio.netlify.app).

I'm an AI Engineer Team Lead. I build Generative AI products, AI agents and RAG systems, and I own each project from the first conversation about the need to a live production system.

**Tech stack** - React, TypeScript, Vite, GSAP, Three.js, WebGL, HTML, CSS

## Run locally

```bash
npm install
npm run dev
```

`npm run build` creates the production build in `dist/`.
